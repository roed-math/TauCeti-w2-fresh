# Lookahead: `relative-proj-closed-immersion` (SchemeAndStackFoundations, Layer 0, §0.3)

Target (README §0.3): if `A_1` is of finite type and `A` is generated in degree one, the graded
map `Sym_{O_S} A_1 → A` is surjective in every positive degree and induces a closed immersion
`relativeProj A → relativeProj (Sym_{O_S} A_1)` over `S` pulling `O(1)` back to `O(1)`
(Stacks 01N0, 01N1), so `relativeProj A → S` is projective.

conflicts, nothing on the branch had been superseded). Status: **complete**: the whole target is
proved, with no `sorry` anywhere on the branch.

## How the target is stated

`TauCeti.AlgebraicGeometry.GradedQuasicoherentAlgebra.relativeProj_closedImmersion` (split 8), for
a graded quasicoherent algebra `A` on `X` generated in degree one in the README's sense (over
every affine open `U`, `Algebra.adjoin Γ(A₀, U) Γ(A₁, U) = ⊤` in `⨁ n, Γ(Aₙ, U)`), proves:

- `Symⁱ A₁ ⟶ Aᵢ` is an epimorphism of module sheaves for every `i > 0` ("surjective in every
  positive degree");
- the induced `f : Proj_X(A) ⟶ Proj_X(Sym A₁)` is a closed immersion with
  `f ≫ toBase = toBase` ("over `S`");
- the glued morphism `f^* 𝒪(n) ⟶ 𝒪(n)` is an isomorphism for every `n : ℤ` (the README asks for
  `n = 1`).

"So `relativeProj A → S` is projective": Tau Ceti has no projective-morphism predicate over a
general base (`Scheme.IsProjectiveOver` on `main` is over an affine base only). With `A₁` of finite
type, the closed immersion into `Proj_X(Sym A₁)` over `X` is literally Stacks' definition of
projective (01W8). The branch also proves its consequence
`isProper_relativeProjToBase_of_adjoin_one_eq_top`: with `[(A.obj.X 1).IsFiniteType]` (Mathlib's
`SheafOfModules.IsFiniteType`), `Proj_X(A) ⟶ X` is proper. This is where the README's finite-type
hypothesis is used; the closed immersion itself does not need it.
